# SIGO — Sistema de Inteligencia y Gestión de Observaciones

Base de datos consultable de las observaciones técnicas que SENACE hace a los
estudios (ITS) de las mineras clientes de Sugle S.A.C. — herramienta de
control de calidad para minimizar observaciones antes de presentar estudios.

Antes de desplegar, configurar como secretos del entorno:

- `SUPABASE_URL`
- `SUPABASE_ANON_KEY`
